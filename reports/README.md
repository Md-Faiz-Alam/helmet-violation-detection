# Reports

Generated by the scripts in `scripts/`. Re-run them after changing the model or thresholds.

| Report | Script | What it answers |
|---|---|---|
| [thresholds.md](thresholds.md) | `tune_thresholds.py` | Which confidence threshold catches the most violators without too many false alarms? |
| [error_analysis.md](error_analysis.md) + [gallery](error_analysis/) | `error_analysis.py` | What kinds of mistakes does the model make, and on which objects? |
| [dataset_audit.md](dataset_audit.md) | `dataset_audit.py` | What is in each split (motorcycle vs bicycle), and does recall depend on it? |
| [association.md](association.md) | `eval_association.py` | Does requiring a bicycle/motorcycle under each head remove false alarms, and at what recall cost? |
| [video_eval.md](video_eval.md) | `eval_video.py` | On the 4 test clips, per rider: how many riders are found, how many violations are real (precision) and how many violators are caught (recall)? |
| [video_eval_1080p.md](video_eval_1080p.md) | `eval_video.py` | The highway test clip at 1080p instead of 720p (does resolution change the result?) |
| [model_comparison.md](model_comparison.md) | `benchmark.py` | Which architecture/resolution is the best accuracy-vs-speed trade-off? (with the dated model decisions) |
| [onnx_benchmark.md](onnx_benchmark.md) | `benchmark_onnx.py` | Does the ONNX Runtime model (FP32 / INT8) give the same accuracy as PyTorch, and how much faster is it on CPU? |
| [model_comparison_headwear.md](model_comparison_headwear.md) | `benchmark.py --data data/headwear_test.yaml` | How do the models do on held-out caps, turbans, hijabs, masks and rear views? |

Validation data is used for tuning and analysis. The test set is only used for final numbers.
