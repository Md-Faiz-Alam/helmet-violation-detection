# Reports

Every number in the README and the guides comes from one of these reports. Each is generated by a script in
[`scripts/`](../scripts/) (or written from its output) and dated inside. Validation data is used for choosing and
tuning; the test data only for reporting.

## Current results

| Report | What it answers | Made with |
|---|---|---|
| [video_eval.md](video_eval.md) | **The headline video result.** On the 4 test clips, scored per rider with the live settings: how many violators are caught, how many logs are real, how many plates are read? | `track_video.py` + `eval_video.py` |
| [model_comparison.md](model_comparison.md) | Which of the 9 trained models is the best accuracy / speed trade-off? (with the dated model decisions) | `benchmark.py` |
| [model_comparison_headwear.md](model_comparison_headwear.md) | How do the models do on 635 held-out images of caps, turbans, hijabs, masks and rear views? | `benchmark.py --data data/headwear_test.yaml` |
| [thresholds.md](thresholds.md) | Which confidence threshold catches the most violators without too many false alarms? | `tune_thresholds.py` |
| [onnx_benchmark.md](onnx_benchmark.md) | Does the ONNX model (FP32 / INT8) match PyTorch, and how much faster is it on a CPU? | `benchmark_onnx.py` |

## Decisions about the video pipeline

Each change to the live video pipeline was chosen on the validation clips and checked on the test clips; these
reports hold the evidence, including what was tried and rejected.

| Report | Question | Outcome |
|---|---|---|
| [video_riding_check.md](video_riding_check.md) | Only log heads that sit on a motorcycle (not pedestrians or cyclists)? Does checking that the person moves *with* the motorcycle help? | riding check **adopted**; motion check **rejected** |
| [video_duplicate_logs.md](video_duplicate_logs.md) | Link a violator who is hidden for a moment to their first log instead of logging them again? | **adopted** |
| [video_input_size.md](video_input_size.md) | Does a larger detector input (960, 1280 px) catch more violators? | **not adopted** (helped on validation, not on test) |
| [runtime_parity.md](runtime_parity.md) | Does the torch-free pipeline (ONNX Runtime + numpy ByteTrack) make the same decisions as PyTorch, and how much faster is it? | identical decisions, about 2× faster |
| [association.md](association.md) | Does a head-on-a-vehicle filter remove photo false alarms, and at what recall cost? | **rejected** for photos; reused for plates and the riding check |

Reports describe the system as it was on the date they were made. When a later change makes a number out of date,
the report keeps it and the newer report says what changed.
